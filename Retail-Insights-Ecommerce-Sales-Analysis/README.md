# Retail Insights – E-Commerce Sales Analysis

This project is part of my Data Science internship task.

I selected the Superstore Sales Dataset to understand how sales and profit vary across different regions, categories, and customer segments. The goal is to clean the dataset, explore the data, identify trends, and generate business insights using data analysis and visualization techniques.

### What I plan to do
- Clean and preprocess the dataset
- Handle missing values and duplicates
- Perform Exploratory Data Analysis (EDA)
- Create visualizations to identify patterns
- Find business insights from sales and profit data
- Build a dashboard for better presentation of results

### Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
